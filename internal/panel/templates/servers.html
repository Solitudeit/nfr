添加服务器

目标服务器的 NFR 控制端口地址，通常以 :8443 结尾。
在对方面板的 设置 页创建，建议使用 admin 权限。
留空则首次连接时信任并记住指纹；之后指纹变化会被拒绝。

怎样把另一台接进来

  1. 在对方机器上启动 nfr server。
  2. 打开它的面板，在 设置 里启用 REST API。
  3. 到 设置 → API 密钥 创建一把 admin 密钥并复制。
  4. 回到这里填写地址与密钥即可。
