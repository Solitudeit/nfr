添加服务器

凭据在本地加密落盘，首次连接支持 TOFU 证书指纹校验。

目标服务器的 NFR 控制端口地址，默认以 :8443 结尾。
在目标面板的 设置 → REST API 创建，建议使用 admin 权限。
证书指纹留空时，首次连接自动信任并记住（TOFU）；后续变化将拒绝连接。

跨服务器纳管指南

被纳管实例仍保持完全独立，数据流量不经由本机中转。

  1. 部署并启动目标 nfrs确保其 8443 控制端口可由本机访问。
  2. 开启目标实例的 REST API在对方控制台的 设置 页启用 REST API 开关。
  3. 创建 admin 权限密钥复制一次性明文密钥并填入左侧表单即可。
