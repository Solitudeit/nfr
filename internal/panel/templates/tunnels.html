HTTP 站点

端口直连，或按域名分流

分配一个公网端口，访客直接访问 http://服务器IP:端口；也可以绑定域名，复用 80 / 443 按 Host 分流。

  • 端口模式不需要域名和证书
  • 域名模式需要把域名解析到这台服务器
  • 自动补 X-Forwarded-*，支持 WebSocket

TCP 端口

独立端口，适合任意协议

从端口池里分配一个公网端口，原样转发 TCP 字节。适合 SSH、数据库和远程桌面。

  • 端口从设置里的区间分配，用完为止
  • 支持任意 TCP 协议，包括长连接
  • 不需要域名，也不需要证书
